yt-mp3-uploader 개인정보처리방침

시행일: 2026년 10월 8일 · 운영자: 김도경 (dkkim.esq@gmail.com)

yt-mp3-uploader는 운영자 본인이 자신의 YouTube 채널에 동영상을 올리기 위해 개인적으로 사용하는 도구입니다. 일반 이용자에게 제공되는 서비스가 아닙니다.

  • 요청하는 권한은 YouTube 동영상 업로드 권한(https://www.googleapis.com/auth/youtube.upload) 하나입니다.
  • Google 계정 정보, 시청 기록, 채널 데이터를 수집하거나 열람하지 않습니다.
  • 인증 토큰은 운영자 본인의 컴퓨터에만 저장되며, 제3자에게 전송·판매·공유하지 않습니다.
  • Google API에서 받은 정보는 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.
  • 권한은 언제든지 https://myaccount.google.com/permissions 에서 철회할 수 있습니다.

Privacy Policy (English)

yt-mp3-uploader is a personal tool used only by its operator (Cassian Kim (김도경), dkkim.esq@gmail.com) to upload videos to the operator's own YouTube channel. It requests only the youtube.upload scope, collects no other user data, stores the OAuth token only on the operator's own computer, and never transfers, sells, or shares it. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at https://myaccount.google.com/permissions.
